# 报告4：单仓轮动开仓

入口：[轮动开仓与期限性价比](skhy_report4_rotation.html)。

- 每次1 Call＋1 Put，同行权价和到期日；平仓后才重开，允许追加资金。
- 六档期限选择：固定本周五（周五买下周）、固定下周五、下周加价上限10%/25%/50%、权利金/股价/√剩余自然日最低。
- 观察价与实际模拟开仓价均要求权利金/股价≤12%。每张100股，分子分母同乘100，所得比率一致。
- 平仓规则冻结为报告3的涨侧150%、跌侧10%；到期周三、周四、周五分别乘75%、50%、25%。以本次入场股价为方向基准。
- 首次7月31日10:00；平仓后下一个10分钟检查点、且不早于10:00，15:30后顺延下一交易日。过贵则下一交易日10:00重试。
- 若起始候选缺成交价，当天每10分钟继续等报价，行权价固定在本次开始评估时选择；不把后来的股票变化倒灌进早先的选约。
- 选约只用历史当日已存在的合约、当时已完成分钟价；两腿价格年龄≤10分钟。买卖取信号至少一分钟后的首个股票/两腿共同分钟开盘价。开仓还须满足12%限额，否则继续等到15:30。
- 没有后续共同成交分钟的退出信号不会虚构成交，等待到期结算或期末估值。无0DTE新开仓，周五仅考虑下周五。
- 灵活期限方案只有一个候选合格时可选择该候选；缺价不同于过贵。报告保留每次决策候选与来源分钟。
- 全部收益为毛收益。合计=已实现+期末持仓估值，不年化。样本内比较，非独立样本外验证。

在此目录运行：

```sh
python3 -B rotation_backtest.py
python3 -B verify_rotation.py
python3 -B add_rotation_example.py
python3 -B build_rotation_report.py
```

仅使用缓存复现（日期须与已下载缓存相同）：

```sh
python3 -B rotation_backtest.py --offline --end 2026-10-08
```

下载缓存位于 `rotation_cache/`，原始数据通过既有付费行情接口获取；密钥从既有数据程序读取，不存入缓存或报告。`rotation_results.json` 是原始回测结果，`rotation_report_data.json` 增加绘图序列与现金需求统计。运行时可能生成 `rotation_cache/checkpoints/`，其中的单方案结果为计算检查点，可用于下载中断后的诊断。报告1/2/3保持原状。

周二3天与10天仅为直觉示例；实际比较使用距离到期当日16:00的精确自然天数。平方根时间指标是定价近似下的启发式，不是实际隐含波动率，不等于波动预测或期望收益。
