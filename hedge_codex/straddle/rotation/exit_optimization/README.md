# 报告5：固定平方根时间选约，优化轮动退出

[打开报告5](skhy_report5_exit_optimization.html)。保留报告4，独立比较44组规则；区间固定为2026-07-31至2026-10-08。

## 不变的条件

每次1 Call＋1 Put，同行权价和到期日、最多一组持仓。开仓评分为（两腿权利金／股价）／√剩余自然日，取合格候选中较低者；观察价格与模拟买入价格均受12%费用上限约束。仅比较本周五和下周五，周五不新买当天到期合约。平仓后在下一个10分钟检查点、且不早于10:00重开；15:30后顺延。没有合格入场则下一交易日10:00再试。

## 搜索范围

- 初始涨侧／跌侧盈利目标：150%／10%、80%／10%、40%／10%、80%／5%。
- 到期周三、周四、周五分别乘75%、50%、25%；每次新开仓重置成本、方向基准和到期周。
- 止损：不设置或组合亏损35%。
- 强平：不强平、提前3天10:00、提前3天15:30、提前2天10:00、提前2天15:30。
- 上述40组，另加4组没有止盈止损、仅按上述时间强平。

提前天数按自然日算，周五到期的3天／2天分别是周二／周三。强平到点就发出信号，不要求盈利或有新鲜估值；仍用信号至少一分钟后的首个两腿及股票共同成交分钟开盘价模拟退出。没有后续共同成交分钟不会伪造卖出，等待结算或期末估值。强平优先于同一观察点的止盈和止损。

选约评分公式保持不变；强平规则会缩小可选期限：计划强平时点已到的合约不再买入，实际入场时间也必须在强平截止前，防止卖出后立即买回。因而不同强平规则产生不同的真实轮动路径，并非事后改写同一组交易的退出价格。

收益为毛收益，包含期末浮盈亏，不扣交易费用、不年化。全部历史均用于选参，不保证样本外最优。最大回撤按可用估值点计算；累计权利金为周转总额；最低现金需求允许盈利再投资及追加资金。

## 复现

依赖父目录的 `rotation_backtest.py` 和 `build_rotation_report.py`，行情通过既有付费接口加载，密钥不写入目录。

```sh
python3 -B optimize_rotation_exits.py --end 2026-10-08
python3 -B verify_exit_optimization.py
python3 -B build_exit_report.py
```

离线重算：增加 `--offline`。缓存位于 `market_cache/`。分策略检查点在 `checkpoints/日期/`，删除对应日期检查点可强制重算；改变参数或程序逻辑后应删除旧检查点。完整明细是 `exit_optimization_results.json`，网页数据包含所有规则、逐笔交易和收益曲线。

`imported_data_provenance.json` 记录从旧历史库复用的已到期合约、原始文件摘要和数据覆盖区间。导入前58份重叠合约的全部正常交易时段分钟数据与当前下载缓存完全一致；只导入旧库截止日之前已到期且覆盖完整的合约。其余行情按需下载。
