# 六轮全量训练＋时间递减退出

六轮已结束周期全部训练：7/31、8/7、8/14、8/21、8/28、9/4。9/11未到期只展示，完全不参与参数排名。无训练/验证拆分。

复现（在time目录）：
```sh
python3 -B analyze_all6.py
python3 -B verify_all6.py
python3 -B build_all6.py
```

复用report3_inputs固定行情快照和prior_stock_closes.json，数据截至2026/9/16。每轮1 Call+1 Put，不复投；每腿买入+2%、卖出−2%、每张每次$0.65为标准示例摩擦。信号每10分钟观察，成交至少下一分钟，缺共同成交分钟保留到期。

19,977个候选。新增6套周三/周四/到期周五递减目标，允许不同涨跌侧初始目标，及止损、轮空、周四15:30强制退出。收益目标均为扣摩擦后的组合净收益率。不得再扣一次Theta，历史期权价已包含时间价值变化。

总净收益优先，至少交易2轮；并列按最差轮次、无轮空、非追踪、固定编号排序。最高$2,564.56存在12组并列参数；时间递减与固定目标的实际六轮结果相同。全样本结果不代表未来最优。

all6_rule_scores.json保存所有候选评分；all6_optimization.json保存各类别最佳规则、逐轮账本、仅改变时间阈值的消融对比、各衰减方式最佳参数和成本敏感性。更新报告3入口，同时保留skhy_report3_all6_time_decay.html新链接。旧报告3备份，报告1和2不改。

本报告结论固定于当前六轮；新增数据需同步更改样本设计与报告文字。
