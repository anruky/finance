# 报告3：跨式退出和轮空策略研究

固定研究报告2的7个周期（7/31起，行情截至2026/9/16），6个到期周期选参，未到期周期不选参。每轮1 Call + 1 Put，沿用报告2入场。无需新增下载，输入快照在report3_inputs，历史收盘特征在prior_stock_closes.json。

复现顺序：
```sh
python3 -B analyze_exit.py
python3 -B verify_exit.py
python3 -B plot_comparison.py
python3 -B build_report.py
```

需要Python3.9+、matplotlib。分析搜索8217条规则；标准口径每腿买入加价2%、卖出减价2%，每张每次佣金$0.65。买入价和收益阈值都没有把股票本金计入。9/11未到期不计入排名。

训练为前三轮，验证从8/28开始，8/21周期与训练结束时间重叠，不计入验证。滚动选参也排除当日上午未到期的前一轮。盘中信号仅用完成分钟；退出以信号后至少一分钟的共同成交分钟估算，不保证真实可成交。

规则并列时优先最差轮次较好、无过滤、非追踪止盈、编号较小。具体下跌2%与较高阈值可能并列，并不代表精确最优。

研究结论是样本内有候选改善，但训练选出的规则后续验证失败。HTML包含事后赢家、训练候选、费用过滤、逐周期、执行敏感性和参数邻域。全样本排名属于事后比较，不能算验证。没有改动原报告1或报告2。没有下单或启动定时交易。

本研究样本与叙述固定于上述七轮；若换入新行情，应同步扩展训练/验证设计并重新核对报告文字，不能直接套用本次静态结论。
