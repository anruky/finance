# 退出规则优化

用户要求优化涨跌阈值及指标退出。本研究保持原10:00决策、最晚15:59执行、策略1固定10组且允许补资、策略2原资金账户。129个预声明规则，两个策略分别扫描。新增规则通过 `run_intraday(exit_rule=..., feature_map=...)` 传入，默认行为仍为15%/8%，不以全期最优自动替换基准。

- 固定阈值77组；ATR16组；时间6组；组合止盈止损12组；利润回撤6组；放量反向6组；波动收缩6组。
- 前31个交易日（至08-24）为训练；后13日（08-25至09-11）验证。该后段此前已看过，严格标为回顾性时间验证。
- 训练分数：现金流中性净收益减0.5倍累计净收益曲线最大美元回撤；不是用后段收益挑选。
- 持仓跨分界连续处理；收益按资产减累计入金的变化分段。单位净值回撤剔除入金。
- 三段walk-forward训练长度20、28、36日；每次只用前段选择，在同一个真实接续账户上应用至下一8日，保留现有持仓。不是拼接最佳候选曲线。
- 特征不读取当日收盘、全天高低或全天成交量。ATR到前日，半小时量比用09:30–09:59，组合盈亏用09:55–09:59最新共同分钟；缺数据不回填10:00后的价格。
- 退出后仍尝试立即重开，未改变入场择时。这一点可能限制退出优化的收益。

策略1训练选择涨7%/跌12.5%，全期-$13,479.80，后段-$12,075.60，未改善基准后段。全期事后最高为涨7%/跌5%，-$7,560.60；并非未来通用最优。策略2训练及全期最高为涨7.5%/跌5%，全期-$58.53，后段仍亏损。该129组没有全期盈利方案。

报告：skhy_exit_optimization_report.html。结果：skhy_exit_optimization_results.json。当前基准报告顶部链接本研究，保留原基准。

复现：
1. `python3 -B optimize_exits.py`
2. `python3 -B gen_exit_optimization_report.py`
3. `python3 -B gen_intraday_report.py`
4. `python3 -B -m unittest test_intraday test_exit_rules`

分钟源数据和已有费用假设仍有流动性及时间同步限制。价格成交量小于仓位、同一分钟不同秒、等待较久才成交等风险未由参数优化消除。未来新数据验证、历史Bid/Ask支持和入场条件研究仍然必要。
