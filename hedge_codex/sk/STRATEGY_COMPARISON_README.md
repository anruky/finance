# SKHY 两策略对比

运行：`python3 -B gen_strategy_comparison.py`，或沿用 `python3 -B gen_straddle_report.py`。
报告：skhy_straddle_report.html。数据：skhy_strategy_comparison_results.json。

策略1：固定10 Call + 10 Put；策略2：持续持有100股，每轮2 Put。
统一下跌15% / 上涨8%，以前日收盘触发次日滚动。原引擎价格、费用、期限和流动性规则保留；同初始账户资金$22,852.50，不追加资金。策略1现金不足10组全部成本时跳过。

生成器实际重跑两个引擎，核对14轮信号日、交易日、行权价和到期日一致后逐轮比较。策略2股票成本列为轮初市值而非重复买股的现金支出，逐轮收益包含股票价格变动及2 Put净收益；首次股票买入费用列在轮次外。股票首买日07-13，首轮期权07-15，两天间收益必须在账户对账中单独列出。

生成器同时重跑0%、2%、5%滑点敏感性。资金收益率使用账户本金；轮收益率使用轮初组合成本/市值，不能相加。未平仓最后一轮按市值计价。此前单组及满仓研究文件保留为历史资料；当前对比以本报告和新的结果JSON为准。
