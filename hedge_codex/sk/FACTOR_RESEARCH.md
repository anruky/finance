## 定义与时间顺序

特征使用t日收盘及以前的信息，标签只包含t+1起的未来交易日。

- RVOL5/20 = t日成交量 / 此前5/20日均量，分母不含t日。
- 当日振幅 = 100×(High−Low)/Close。
- ATR5/14 = 简单平均真实波幅 / t日Close ×100；未用Wilder ATR。
- 近n日RV = 100×sqrt(sum(log(Close_j/Close_(j−1))²))，包含t日，不年化。
- 未来n日RV同式，但只包含t+1至t+n；日线RV忽略盘中路径，不等于真实高频实现波动。
- 最大收盘位移 = max(|Close_(t+j)/Close_t−1|)×100，j=1…5。
- 第5日净位移 = |Close_(t+5)/Close_t−1|×100；不包含方向。
- 未来高低幅度 = (未来5日最高High−最低Low)/Close_t×100，保留在JSON。
- 对数成交量、日量变化、相对成交金额、跳空、跌幅、偏离MA20、布林带宽度和单位成交金额价格冲击见`basic_features`。
- 7天Put因子使用当天已挂牌、有成交、满足原流动性/异常检查的近ATM合约。
  两张裸保费率=2P/S×100；时间价值率扣除内在价值后乘sqrt(7/日历DTE)，只是期限归一的粗代理，不是正式IV估计。
- 外部标的RV5和日绝对涨跌在美股同日收盘后对齐；外部使用供应商拆股调整数据，仅作预测因子，不参与SKHY期权估值。

## 样本划分及稳定性

开发期标签必须在2026-08-24或之前结束，清除跨越切分点的前瞻标签。
新增期信号日在08-24之后，且未来窗口必须已有完整数据，因此5日标签最多8个。
高低组门槛固定为开发期特征中位数；开发期不足8个观察点就不分组。空组不能解释为通过验证。

主表为Spearman秩相关；JSON同时保留Pearson、1/3/5/10日相关、去掉最初10个信号日的结果。
时间/RV5偏相关：先对变量做秩变换，再分别对截距、上市后的观察天数秩、近期RV5秩回归，相关残差。
若因子本身就是RV5，该偏相关不定义。控制相关不代表因果。

不重叠观察窗：从第一个有用信号日顺序选择，下一信号日不得早于前一窗口结束日；共享边界收盘、未来收益区间不重叠。
主样本仍大量重叠；移动块重采样使用块长5、800次、种子20260914，仅作描述性95%区间。
未实施多重检验校正，上市早期非平稳性和26个因子的选择偏差仍存在；不宣称显著性或已获得预测能力。

长历史检查是每个标的自己的指标预测自己的未来RV，没有把这些样本拼成SKHY样本。
实际策略净收益检查用原交易的信号日指标，剔除期末未平仓轮；RVOL5/RV5/ATR5仅11轮，最早两个轮次因暖机不足缺失，包含最大盈利轮。

## 复现

Python 3.9+；因子计算使用NumPy；联网下载额外需要requests。

```sh
# 联网时在环境中配置 POLYGON_API_KEY 或 MASSIVE_API_KEY
python3 refresh_factor_data.py --end 2026-09-11
python3 analyze_factors.py
python3 gen_simulation_report.py
python3 -m unittest -v test_factors.py test_backtest.py
```

若更新SKHY行情，请先生成其回测结果`results.json`，再重算因子。报告会检查因子对应行情的SHA256，拒绝把旧因子嫁接到不同的行情包。
`gen_simulation_report.py`发现`factor_analysis.json`后会自动插入因子章节并把展示范围固定为2张Put。
