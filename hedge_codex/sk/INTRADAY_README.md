# 追加资金与延长等待窗口

当前主情景：策略1固定10 Call+10 Put，现金不足时在成交前按缺口追加；策略2沿用原本金。10:00作出信号和选档，逐分钟等待至15:59，使用股票和所有必要期权都有成交的最早共同分钟。旧仓成交后下一分钟才可开新仓。超过一小时的分钟索引已正确跨小时处理。仍不将独立不同分钟价格拼接为同时成交。

本样本两策略均15轮，资金不足、缺价开仓、缺价平仓均为0，到期结算例外0。7月13日无满足上午成交量条件的候选，按原筛选规则不交易。策略1最晚入场10:57，5次追加共$15,035.90，累计投入$37,888.40，期末$11,960，净亏损$25,928.40。策略2无需追加资金，净亏损$2,571.81。

收益=期末资产-全部入金；return_pct为净收益/累计投入的简单未年化比率；xirr_pct按每笔实际日期计算年化资金收益，期末持仓市值作为终值。该样本不足一年，不能把XIRR当可持续年回报。曲线unit_nav按入金前净资产增加份额，入金不改变单位净值；mdd_pct为此单位净值的最大回撤。mdd金额为初始资金尺度下的单位净值回撤，不能解释成实际累计资金的美元回撤。

JSON deposits保存逐笔入金。unit_curve保存剔除入金后的净值，curve保存真实账户资产与累计投入。策略1在19个开仓腿次中张数超过该分钟总成交量；该模型不具备订单簿容量验证，不能保证真实成交。窗口越长也会偏离开盘半小时的本意，10:00冻结的行权价在晚些时候可能不再平值。

# 执行窗口更新

默认10:00–10:05，先固定10:00时的信号与候选合约，再逐分钟寻找股票及所需期权都成交的最早共同分钟。取该分钟各腿首笔价；不独立寻找各腿的不同分钟，也不挑选有利价格。10:05是包含10:05:00–10:05:59的分钟桶。

旧仓在窗口内平仓后，新仓从下一分钟起寻找，保证时间不倒置。若旧仓10:05才退出，新仓本日跳过。报告逐轮展示真实模拟入场和退出分钟。

主情景5分钟，另重跑0和10分钟窗口敏感性；所有窗口采用相同先平仓后开仓规则，因此0分钟结果可能不同于旧版允许同一分钟平仓再开仓的版本。

# SKHY 美东10:00分钟回测

用户确认：每天10:00判断下跌15%/上涨8%并滚动；策略2每轮卖旧股票和Put，再同时买100股与新Put。策略1账户固定10 Call+10 Put，逐轮表除以10。账户初始本金均$22,852.50。

## 执行与信号

- 当天09:59分钟收盘在10:00可见，用于涨跌触发及ATM行权价排序。
- 按目标2天、实际1–7天期限优先，其次与当时股价最近；行权价偏离不超过3%。
- 共同候选Call/Put在09:30–09:59各成交至少10张。该筛选替代旧前日成交量规则，避免用全天成交量；保持配对候选池一致，不代表Put策略实盘必须检查Call。
- 确定候选后使用10:00分钟各腿首笔成交价。缺少该分钟则不成交；不换用全天收盘，不利用之后价格重新选合约。
- 首笔成交可能不同秒，不是同步报价。10组可能超过分钟成交量；结果标记但未施加容量限制，滑点不能保证成交。
- 缺退出腿数据时整个组合延期；到期仍缺10:00行情时，收盘现金等价结算为显式例外，股票同时处置，不能称为10:00交易。
- 股票每轮买卖各5bps，期权每边2%滑点最低1美分/股、每张0.65佣金。到期现金等价结算计行权及股票处置摩擦，但不模拟真实交割融资和结算等待。
- 收盘价只用于日终净值与期末估值（另有显式到期结算例外）。没有外部注资、贷款和现金利息。

## 结果限制

244个候选合约的分钟数据，日期07-13至09-11。主情景策略1仅2轮，策略2为8轮。缺分钟、资金不足、到期例外导致不同路径；没有入场、退出日期及时间都一致的轮次。报告不强算不匹配轮次的差额。输出只是“严格10:00分钟有成交才成交”的条件模拟，不能解释为实际有买卖报价时的完整策略回报。旧收盘策略结果不可直接作执行时间因素的单变量对照，选档、触发、股票重买和成交量过滤也变化了。

结果JSON含每笔交易、逐日净值、跳单及延期事件。旧报告及旧数据保存在部署时的备份目录。

## 复现

`python3 -B gen_intraday_report.py`

`python3 -B -m unittest test_intraday`

重新下载（环境变量POLYGON_API_KEY，不在程序内存放密钥）：
`python3 -B refresh_intraday.py --project-dir . --output-dir data/intraday_cache`
然后通过 `--data data/intraday_cache/SKHY_intraday.json` 生成报告。缓存按合约保存；要刷新同一时间窗需先另选输出目录。默认报告读取 `data/SKHY_intraday.json`。
