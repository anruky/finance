## 模型

同一行权价、同一到期日、乘数100的1张Call＋1张Put。默认目标2天，DTE范围1–7天。
前日收盘相对实际入场股票价格下跌15%或上涨8%触发滚动；次日用两腿日线末价模拟成交。
Call匹配原Put选择，不独立改变行权价。两腿前日均需合格成交量至少10张，Call还需历史as_of挂牌记录。
前日价格低于对应内在价值超过0.05美元时不入选。

买卖每边价格摩擦2%，最低0.01美元/股；每张每边佣金0.65美元。
两腿缺任一退出价则都延迟退出，缺任一入场价则不开组合，不能留下未经计划的单腿。
缺估值则用上次价格与内在价值的较高值作显式估计，标记异常，不能作为经过验证的收益。

到期按内在价值作等价现金结算：实值腿计1美元行权费、100股价值的5bps平仓摩擦，保持零股票。
未模拟提前行权、实际结算等待、临时短股借券或税费。期末未平仓仅估值，不计假设出售费用。

主情景所有现金0利息；额外4%年化情景采用ACT/365、前日现金、自然天数计息。
现金利息不改变交易路径、不增加合约数；4%仅为假设，不是账户实时利率。

## 平价差异诊断

配对表固定原策略的入场和退出日期。原组合每轮盈亏为该段100股变化＋双Put净损益；
跨式为同日同档的Call＋Put净损益。期末持有轮按末价估值，未伪装为已实现利润。

平价偏差定义为 `100*(S + P - C - K)`，忽略利率、分红和美式提前行权差异。
两种结构轮内毛盈亏之差为退出偏差减入场偏差，费用另计。
该偏差使用不同步日线末价，只供诊断，不能用于判定可执行套利。

## 数据与复现

- `data/SKHY_put_history.json`：原已刷新股票及Put数据。
- `data/SKHY_call_history.json`：新拉取94个对应Call的完整日线、历史挂牌记录和来源。
- `skhy_straddle_results.json`：两种策略、基准、配对轮次、49组阈值、4种期限、滑点和利息敏感性。
- `backtest_straddle.py`：跨式引擎，依赖已有`backtest_audited.py`和`refresh_data.py`。
- `refresh_straddle_data.py`：根据原Put候选拉取匹配Call；凭证只从环境变量读取。
- `gen_straddle_report.py`：生成独立新HTML报告。
- `test_straddle.py`：7项资金、双腿成交、滞后信号、到期、利息和会计一致性检查。

Python 3.9+，离线计算只需标准库；联网数据刷新需要requests。

```sh
# 离线重跑并生成报告
python3 gen_straddle_report.py
python3 -m unittest -v test_straddle.py

# 补拉Call时，先在环境配置POLYGON_API_KEY或MASSIVE_API_KEY
python3 refresh_straddle_data.py
python3 gen_straddle_report.py
```
