### 5.2 🔥 混元 Hy3 正式版发布——AI 重组后首份答卷

| 要素 | 详情 |
|------|------|
| **发布时间** | 7/6 正式发布（距 4/23 Preview 版仅 10 周） |
| **模型架构** | MoE，总参数 **2950 亿**，激活 **210 亿**，支持 **256K** 上下文 |
| **关键提升** | 幻觉率 12.5%→**5.4%**；工具调用稳定性提升；多轮对话记忆增强 |
| **性能对比** | 整体达 GLM-5.1 同级；明显领先 MiniMax M3；比肩 2-5 倍参数旗舰模型 |
| **接入产品** | WorkBuddy/CodeBuddy、元宝、Marvis、ima、微信公众号客服、WeGame |
| **用户增长** | 日均 Token 消耗 **增长 20 倍**；WorkBuddy 选择 Hy3 用户 **增长 6 倍** |
| **商业化** | 元宝上线**免费 Agent**功能（可生成 PPT/Word/Excel/PDF/HTML） |
| **开源** | Apache 2.0 协议，已在 Huggingface/ModelScope 上线，将覆盖 OpenRouter 等海外平台 |

> **伯恩斯坦评价**：Hy3 虽非前沿模型，但性能已足以支撑微信生态 Agent 落地。腾讯 AI 战略正从"模型研发"转向"商业落地"，核心衡量指标将从"聊天机器人使用量"转向"Agent 交易规模"。Agent 商业化更可能采用 **B 端收费模式**（商家订阅获更多 AI 流量），而非 C 端直接订阅。
>
> **国信证券评价**：WorkBuddy 为混元模型迭代提供高价值方向，是"国内人数最高的中国办公室智能体平台"，3 月 PC 端月访问量 885 万。预计 2026-2028 年调整后净利润 2758/3132/3486 亿元。
>
> **待解决问题**：伯恩斯坦指出，腾讯重组后的 AI 团队**尚未获得微信数据使用权限**，微信 AI Agent 主要由微信团队独立开发——组织协同仍是观察点。
>
