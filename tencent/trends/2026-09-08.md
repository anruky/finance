## 三、🔥 汇丰 NDR 路演深度拆解（本期最核心增量）

> **背景**：汇丰于 **2026 年 9 月 3 日**举办 NDR（非交易路演）电话会议，腾讯首席战略官 **James Mitchell** 出席并披露多项关键信息。汇丰会后维持**买入**评级、目标价 **655 港元**（基于当时股价 442.80，隐含 +47.9%）。

### 3.1 Capex：二季度见顶，四季度正常化 ⭐⭐⭐⭐⭐

| 维度 | 管理层表述 | 解读 |
|------|-----------|------|
| **Q2 定位** | 二季度资本开支水平可视为**新常态基准**，仍有上下浮动空间 | 528 亿/季不是"失控"，是平台期 |
| **跃升节点** | **资本密集度的主要跃升已在 Q2 完成** | ⭐ 最关键的增量信息 |
| **节奏** | 预付款项可能**延续至 Q3**，**Q4 起趋于正常化** | ⭐ FCF 压力 Q4 缓解 |
| **全年预测** | 汇丰预计 2026 全年 Capex 约 **2124 亿元**（2025 年 1127 亿，近乎翻倍） | 高但可控 |
| **采购计划** | 今年余下时间及 2027 年持续采购芯片 | 长期承诺不变 |

> **🔑 为什么这是本期最大利好**：8/13 中报后股价 -4.25% 的核心导火索就是"Capex 527.8 亿 + FCF 转负 −138 亿"引发的**投入失控恐慌**。管理层这次明确给出**时间表和顶部位置**——"跃升已完成、Q4 正常化"，等于给市场吃了一颗定心丸。虽然 Capex 绝对值仍高，但**"看不到头的担忧"变成了"看得见的终点"**。

### 3.2 500 亿内存预付款："五年一遇"的战略性采购

| 维度 | 数据 |
|------|------|
| **金额** | Q2 预付逾 **500 亿元人民币**（约 70 亿美元） |
| **标的** | 锁定**当前及下一代**内存芯片——不只是普通 DRAM，包含面向 AI 推理、**KV-Cache 卸载**的高速存储硬件 |
| **定性** | 管理层称为**"五年一遇"**的部分一次性支出 |
| **目的** | 应对内存芯片供应瓶颈 |
| **呼应** | 与此前和**长鑫存储**签署的价值超 200 亿元、3–5 年服务器 DRAM 长期供应协议相呼应 |
| **行业佐证** | 韩国 KB 券商：三星、SK 海力士渠道库存不足 10 天，明年存储需求大于供给 10 个百分点 |

> **💡 战略逻辑闭环**：管理层同时指出 **小微采用轻量级 WeLM 模型，运行成本显著低于 HY 或 WorkBuddy**。结合"付费 Agent 用户每轮对话/任务记忆都疯狂消耗 KV-Cache"——**腾讯砸 500 亿锁存储，是为了给未来付费 Agent 规模化铺路**。这不是被动挨宰，是主动卡位。

### 3.3 Harness 变现数据首次披露 ⭐⭐⭐⭐⭐

| 指标 | 数据 | 含义 |
|------|------|------|
| **MaaS 毛利率** | 约 **40%**（当前回报率最高） | 短期最赚钱 |
| **Harness 付费用户推理毛利率** | **已追平 MaaS（约 40%）** | ⭐ 变现能力获验证 |
| **付费用户 Token 消耗** | **是免费用户的 2 倍以上** | ⭐ 用户分层变现能力强 |
| **战略选择** | **放弃短期更赚钱的 MaaS，把长期资源押注 Harness + 混元训练** | 主动取舍 |

**管理层为什么这么选？**
> - MaaS 毛利率**未来承压**：① 市场需求从训练转向推理 ② 模型厂商逐步自建算力设施、降低对云服务商分发渠道的依赖
> - Harness 上行空间来自：推理需求增加 + **用户粘性提升（任务历史记忆功能改善）** + 免费用户向付费持续转化
> - 拥有自研 SOTA 模型有助于**长期改善利润率结构**

> **🔑 直击痛点**：此前市场对腾讯 AI 的核心质疑是"**投入大但变现路径不清**"。这次管理层第一次给出可验证的变现数据——**付费用户毛利率已与最赚钱的 MaaS 持平、付费用户消耗量是免费的 2 倍**。虽然没披露绝对收入规模，但**单位经济模型（unit economics）第一次被证实了**。

### 3.4 费用结构变化与自研模型战略

| 维度 | 内容 |
|------|------|
| **Q2 费用驱动切换** | 从 Q1 的**元宝营销费用** → 转向**混元大模型 + WorkBuddy/CodeBuddy 等 Harness 产品运营支出** |
| **小微成本优势** | 采用轻量级 **WeLM** 模型，运行成本显著低于 HY 或 WorkBuddy |
| **模型研发延误** | 管理层**承认团队重组使模型研发推迟 6–9 个月** |
| **提速成果** | 新统一汇报架构使发布节奏加快至**每两个月一次** |
| **CodeBuddy 短板补齐** | Hy4 preview 代码能力大幅提升，可承接部分 CodeBuddy 代码请求 |
| **产品分层策略** | 高端复杂 Agent 任务用大模型（HY3/HY4），简单任务切小模型（WeLM），控制算力成本 |

## 五、🔥 微信"小微 AI 社交"内测（远期催化剂首次具象化）

### 5.1 功能形态

| 维度 | 内容 |
|------|------|
| **核心机制** | 用户的小微**直接找到好友的小微**对话；用户只告知自己小微诉求，由它前往对方小微沟通 |
| **交互流程** | 对方**授权确认** → **两个 AI 先行交流** → 结果带回 → **需要用户拍板时提醒确认** |
| **与"代发消息"区别** | 不是替你发消息，而是**两个 AI 先聊，用户仅在授权与决策环节介入** |
| **隐私设计** | AI 间对话记录**只在"小微"专属界面内留存**，与普通聊天窗口完全隔离，不干扰日常消息流 |
| **适用场景** | 约饭、约咖啡、协调日程等低信息量但高频的社交协调 |

### 5.2 "小微"基础信息

| 维度 | 内容 |
|------|------|
| **上线时间** | 2026 年 **6 月中旬**开始小范围内测（6/20 开放），微信版本 **8.0.75** |
| **入口** | 主界面左上角**绿色两点**，或主界面一键右滑 |
| **主模型** | **WeLM**（微信团队自研），部分回答调用 DeepSeek |
| **WeLM 规格** | 支持 **128k tokens**（9–10 万字）上下文，擅长逻辑推理与数学解题；最大特点是**与微信生态深度整合** |
| **已有能力** | 对话操作微信原生功能（发消息、打音视频通话、搜朋友圈）；调起小程序完成挂号/买咖啡/点喜茶/订酒店/打车；搜索视频文章、生成图片与笔记 |
| **官方态度** | 腾讯客服称"目前仅小范围测试，未获名额可留意后续版本更新"；**官方对该消息暂无正面回应，未公布正式上线时间** |

> **🔑 为什么这是 ⭐⭐⭐⭐⭐ 级信号**：刘炽平在 Q2 电话会（Q4-1）描述的终局是"**不只是用户侧有 Agent，大量小程序和商家也会有自己的 Agent，商家 Agent 可与用户 Agent 交互**"、"每个用户都有 Agent，Agent 之间互相交互完成交易"。**"小微 AI 社交"就是这个 Agent-to-Agent 闭环的第一次产品化落地**——虽然只是社交协调场景，但架构验证意义远大于当前功能本身。
>
> **⚠️ 冷静提示**：① 仍是**小范围内测**，无正式上线时间表 ② 官方未正面回应 ③ 商业化路径完全未披露 ④ UBS 在 Q2 电话会追问的"净 take rate / 广告库存稀释"问题**至今无答案**。这是"想象空间"，不是"业绩"。
