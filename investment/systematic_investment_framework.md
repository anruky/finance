# 系统化投资体系总体框架（V0.2 草案）

> 创建：2026-10-27｜版本：V0.2｜定位：2–3人投资研究团队的长期工作框架。框架仍可迭代；各项比例和规则均需验证。

## 总体原则

团队分成三个相互衔接的模块：**长期价值投资研究**、**系统化与量化策略研究**、**投资决策、资金与风险管理**。前两类产生投资判断和策略，第三类负责跨策略的资金分配、执行纪律与整体风险边界。

不把无规则、无法验证的主观短线盯盘作为独立方向。短周期不等于量化；系统化方法也可以用于长期投资。

## 1. 长期价值投资研究

### 1.1 公司研究（含估值与个股决策）

1. 商业模式、竞争格局和护城河：如何赚钱、竞争优势能否持续。
2. 成长性与未来发展：收入、利润的长期驱动因素和3–5年以上情景预测。
3. 财务质量：盈利质量、自由现金流、资本开支、资产负债表。
4. 管理层与资本配置：经营能力、再投资、回购、分红。
5. 长期风险：基本面恶化、行业变化、竞争优势受损、永久性资本损失。
6. 公司估值：保守预测、估值区间、安全边际、下行情景。
7. 个股投资判断：什么价格值得买、什么事实会推翻投资逻辑；具体仓位与组合约束由第3类统筹。

示例研究对象：腾讯、Google。按季度财报更新模型，重大事实变化时及时复核。

### 1.2 宏观研究

1. 经济周期：增长、就业、消费、企业盈利、衰退和复苏。
2. 货币政策与流动性：通胀、政策利率、美债收益率、信用环境、流动性。
3. 市场整体估值与风险：指数估值、风险溢价、市场定价与机会成本。
4. 结构性变化与系统性风险：AI技术变革、贸易与监管、地缘政治、债务和金融体系风险。

目的：评估中长期投资环境、风险与资产相对吸引力，不以预测每天指数涨跌为主要目标。日常新闻只在可能改变企业价值、宏观判断或组合风险时升级研究。

## 2. 系统化与量化策略研究

### 2.1 程序化市场动态与事件监测

- 用程序持续采集、过滤和标注重大新闻、政策、财报、市场数据及高影响力人物公开言论（如特朗普、马斯克、段永平等）。
- 记录事件源头、首次传播、关键放大节点、发生时间和关联资产；避免靠人工每天刷新闻。
- 事件监测是部分策略的输入，不是所有量化策略的必需条件。

### 2.2 市场波动规律与事件影响研究

- 量化事件发生前后收益率、波动率、成交量、期权隐含波动率和持续时间。
- 研究事件触发、传播放大、市场二次反应及统计显著性；区分相关性和可交易的预测优势。
- 海力士期权研究可作为当前案例，逐步检验哪些新闻指标确实有增量价值。

### 2.3 量化策略设计

- 明确策略假设、适用市场状态、可观测信号、进出场规则与失效条件。
- 研究事件驱动、波动率、趋势或其他可验证策略；不预设所有策略都靠新闻。

### 2.4 数据、回测与模型验证

- 数据质量、时间戳对齐、样本外验证、滚动检验、参数稳健性。
- 纳入交易成本、滑点、流动性、期权行权与到期机制，防止前视偏差和过拟合。
- 以风险调整后收益、回撤及不同市场状态下的稳定性评价策略。

### 2.5 策略优化、自动执行与策略内风控

- 自动化信号、下单、监测、异常处理和实盘偏差复盘。
- 策略级风险：单笔损失、连续亏损、最大回撤、策略失效、流动性与执行故障。
- 这些规则属于量化策略内部控制；跨策略总风险预算和统一杠杆限制归第3类。

### 2.6 开源量化框架与技术方案研究

- 优先调研3–5个有代表性的成熟开源框架，重点比较维护状态、许可证、社区、数据接口、回测真实性、股票/期权支持、自动交易及扩展性。
- 复用成熟的数据、回测、执行基础设施，在事件识别、波动建模、策略与执行上进行自主研发和二次优化。
- 开源框架不等于盈利策略；所有策略必须独立验证，不能凭项目排名或回测曲线判断可盈利。
- 原则：**技术基础设施尽量复用，策略优势自主研究和验证。**

## 3. 投资决策、资金与风险管理（团队统一层）

### 3.1 资产配置

股票、债券、现金等资产及市场、行业、策略之间的资金分配；结合公司和宏观研究评估机会成本。

### 3.2 仓位与资金管理

单标的、单策略资金预算和风险限额；凯利公式等方法仅作理论参考，需考虑胜率估计误差、尾部风险和保守缩放，不能机械套用。

### 3.3 建仓与加仓规则

一次性或分批建仓、估值或信号触发、加仓条件、资金占用和执行纪律。

### 3.4 减仓、退出与再平衡

估值变化、投资逻辑失效、策略信号、风险阈值、替代机会及组合再平衡；长期价值投资不机械以固定盈利百分比止盈。

### 3.5 组合整体风险管理

跨标的和跨策略相关性、集中度、总杠杆、流动性、极端情景、组合最大承受回撤及统一风险边界。

**风控分工**：第1类识别企业长期基本面和估值风险；第2类控制策略失效、回撤和执行风险；第3类管理全团队合并后的资金与风险，避免各策略分别安全却在同一市场冲击下同时亏损。

## 团队与后续工作

- 约1–2人重点负责公司与宏观研究；约1人重点负责量化、数据、回测和自动化。
- 两条研究线共享必要数据与风险信息，但分别评价研究和策略质量。
- 后续逐步建立：公司研究模板、宏观指标体系、量化开源框架对比、策略回测规范、组合风险预算和团队决策流程。
