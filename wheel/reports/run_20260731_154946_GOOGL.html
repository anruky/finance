Strategy Logic (Gav Version)

  • Initial: 100 shares + cash (State A), 2 lots total capital
  • Daily Monitor: If price hits call strike -> buy 100 shares on margin (11% ann.). Put stays open.
  • State B (call exercised after Act1): pay off loan -> A. Next: Put 50% / Call 5%
  • State C (put exercised after Act1): sell 200, pay off loan -> A. Next: Put 20% / Call 10%
  • State D (neither after Act1): sell 100, pay off loan -> A. Next: Put 40% / Call 5%
  • State E (put exercised, no Act1): sell 100 -> A. Next: Put 20% / Call 10%
  • State A (neither exercised): stays A. Next: Put 50% / Call 5%
  • Cycle: 18 days to expiry, all states normalize to A position
