## 1. 模型规则与本期判断

| 项目 | 规则 / 判断 |
| --- | --- |
| 记录单位 | **一条记录对应一条事件**；同一天可有多条事件，没有事件的日期不占行。只记录达到重要性门槛的事件。 |
| 事件类别 | 总览分为“可预测事件”和“突发事件”。固定日历、预告活动及已知峰会归为可预测事件，不代表结果可预测；复盘可在分析中补充“半不可预测”等细分。 |
| 短期影响（1–5分） | 对预测周实际交易波动的潜在影响；已被市场定价（price-in）的程度包含在评分中，不另列。 |
| 长期影响（1–5分） | 对未来数年 HBM / DRAM / NAND 需求、竞争格局、利润率或估值逻辑的影响。 |
| 方向 | 仅保留一列，采用预测周短期方向：偏涨 / 偏跌 / 中性 / 双向，可补充基准倾向。 |
| 去重 | 同一事件只计一次；美国盘后公告与次日韩国市场消化归入同一事件。 |
| 冻结与复盘 | 保留原预测、评分和方向；后续只在“实际情况复盘”栏追加实际走势、首要催化、判断误差及改进。突发事件追加新行并注明事前未列入。 |
| **本期核心判断** | **周三开始进入最重要的信息窗口，美光财报是全周最关键的已知产业事件；宏观主要经利率与风险偏好传导。** |
| 原文每日重要性 | 周一 2分；周二 2分；周三 5分；周四 2分（独立事件口径，美光已计入周三）；周五 3分。 |
| 模型定位 | **已知事件风险地图 + 突发事件监控 + 实际市场反应复盘**，不直接等同于涨跌预测模型。 |

## 7. “牌桌上的人”与跨市场成交口径

早上研究目标是实际推动每日买卖和边际价格的交易方，不能只用长期股东名单代替。讨论中出现的“韩国约 55%、美国约 45%”仅保留为**未经本次核实的等值成交量示例**；未取得同期间成交量、存托比例及市场产品身份底稿，不作为正式结论或预测权重。

正式比较前应确认美国所交易产品的发行/存托机制，再将成交量按正确比例换算，统一交易期间，并补充成交金额与价差。若产品为其他包装结构，不能直接当作本股存托凭证。美国市场交易不等于美国国籍投资者，韩国市场的外资也不等于全部美国资金，因此无法据成交场所推导“至少一半参与者是美国人”。

后续可跟踪韩国外资/机构/个人净买卖、美国端量价与价差、跨市场价格反应、期权持仓和做市对冲线索。公开汇总数据通常无法精确识别所有当日交易者，也不能把双边成交量当作不同参与者人数。
