### 1.4 如何把主播观点纳入事件复盘

- **每条观点留五项**：原视频 / 节目链接及时间戳、发布时间与时区、核心判断、判断依据、适用期限与失效条件。注明是事前判断还是事后解释。
- **落到海力士的传导**：将观点归到 HBM / DRAM / NAND 需求、供给与竞争、客户资本开支、利率估值、资金与情绪之一；明确作者是在谈行业、韩国本股，还是 SKHY 美股。
- **与事实和价格对照**：主播引用的新数据回查公告或原始统计；同一新闻被多位主播讨论只算一个事件。保留相反解读，不以观点重复次数代替证据。
- **写入现有报告**：在[市场事件报告](SKHY_weekly_forecast_review_2026-09-27.html)表内只写解读总结；大幅涨跌或观点分歧较大时，把证据、不同解释和价格路径放入“复盘细节”，并从事件行链接过去。

## 八、海力士周报监控规则（2026-10-08 讨论更新）

配合 [海力士周度事件预测与复盘](SKHY_weekly_forecast_review_2026-09-27.md) 使用。每周预测前检查美国与韩国，X 核心账号清单尚未最终确定；以下为来源类别与操作规则，不代表已部署实时监控或自动化。

| 监控范围 | 首要核对来源 | 记录要求 |
| --- | --- | --- |
| 韩国出口、半导体出口、产业与贸易政策 | 韩国主管部门原始公告 | 发布日、实际值、同口径共识、预期差及半导体分项；不能漏掉固定发布日。 |
| 韩国利率、汇率、资金流与休市 | 韩国央行、KRX 官方数据 | 会议日、USD/KRW、外资/机构/个人净买卖；韩国交易日与美国交易日分别记录。 |
| 海力士、三星、美光和 AI 客户 | 公司 IR、官方公告与业绩材料 | 总公司与存储/HBM 分项区分；已有订单和新增订单区分；发布时间和市场可交易窗口。 |
| 美联储、美债与油价 | 美联储、TreasuryDirect、官方利率数据及可靠行情 | 2/10/30 年曲线、拍卖前后变化、实际利率、美元及油价的传导；不靠同日相关性断定因果。 |
| 中美芯片/HBM 政策 | 发布规则的政府部门原文 | 产品范围、许可、生效日、客户/在华业务暴露；传闻单独标注。 |
| X / 快讯 / 产业研究 | 已核实身份的公司、政策发布方及少数产业作者，核心名单待定 | 原始链接、首次发布时间、确认时间、是否旧闻、可信度和验证状态。快讯先作为线索，事实回查原文。 |
| 财经主播 / 视频与播客 | [财经主播与市场解读名单](#market-commentators) | 保存原视频及时间戳、核心判断、依据和适用期限；区分事前预测与事后解释，对照实际价格与其他解读。 |

统一线索字段：事件 ID、来源链接、发布时间（含时区）、发现时间、原文摘要、确认状态、共识及其时间、预期差、短期/长期影响、双向情景、SKHY 价格反应和成交量标签。量比 ≥1.5 或 ≤0.5 才重点调查；原始量缺失则标待核。

旧清单中的人物身份、账号和固定日历需逐项核对后才纳入核心监控，不因已列入旧表便自动视为当前已认证。
